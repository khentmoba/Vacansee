# Quickstart: Admin Dashboard Polish

## Running the Admin Dashboard
1. Log in as an Admin user (ensure `role` is set to `admin` in the Supabase `public.users` table).
2. Navigate to the Admin Portal.
3. Observe the new high-contrast UI (White card theme).

## Testing Signout
1. Click the profile icon in the top-right header.
2. Select "Sign Out".
3. Verify you are redirected to the Login screen and cannot navigate back.

## Verifying Statistics
1. Navigate to the "Ecosystem" tab.
2. Check the summary cards at the top of the screen.
3. Compare the counts (Properties, Owners, Students) with the records in the Supabase dashboard.
